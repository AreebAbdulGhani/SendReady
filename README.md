# SendReady

**Design emails in Adobe Express. Send them anywhere.**

SendReady turns any Adobe Express design into clean, responsive HTML email that pastes directly into Mailchimp, Klaviyo, or HubSpot and renders perfectly across Gmail, Outlook, and mobile.

---

## Website

Live landing page at **https://areebabdulghani.github.io/SendReady/** (once Pages is enabled).

The site is a single static page: `index.html` + `styles.css` + `script.js`. No build step, no dependencies.

### Enable GitHub Pages

1. Push the site branch (`site-v2`) or merge it into `main`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, pick **Deploy from a branch**.
4. Choose the branch and folder `/ (root)`, then **Save**.
5. The site will be live within a minute.

### Local preview

```bash
# any static server works
python3 -m http.server 8080
# then open http://localhost:8080
```
