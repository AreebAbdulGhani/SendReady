# SendReady

Design emails in Adobe Express. Send them anywhere.

SendReady turns any Adobe Express design into clean, responsive HTML email that pastes directly into Mailchimp, Klaviyo, or HubSpot and renders perfectly across Gmail, Outlook, and mobile.

## Website

The landing page is a single static `index.html` served via **GitHub Pages**.

### Enable GitHub Pages

1. Push this repo to `main`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **Deploy from a branch**.
4. Choose **Branch: `main`** and **Folder: `/ (root)`**, then **Save**.
5. Your site will be live at `https://areebabdulghani.github.io/SendReady/` within a minute.

No build step, no dependencies — just HTML and inline CSS.
